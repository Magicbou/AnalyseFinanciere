# InvestPilot

Application d'aide à la décision en investissement fondée sur des données vérifiables, datées et sourcées.

## Principe non négociable
Aucune donnée inventée, aucune estimation présentée comme un fait. Toute donnée financière doit afficher sa source, sa date et son statut de vérification. Les analyses et scénarios doivent être explicitement distingués des données observées.
